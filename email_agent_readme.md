# AI-Powered Autonomous Email Agent

## 📌 Overview
This project is an advanced, multi-modal local AI Email Assistant built in Python. It integrates large language models (via Ollama), graphical human-in-the-loop (HITL) review interfaces (Tkinter), and an autonomous self-correcting memory system (RAG). The agent can draft outgoing emails, parse incoming inboxes, autonomously sweep spam, and learn from user feedback over time to improve its future actions.

The system connects to Yahoo Mail via IMAP and SMTP, utilizing environment variables for secure credential management.

---

## 🚀 Key Features

* **Local LLM Integration:** Powered by local `ollama` (defaulting to the `huihui_ai/qwen2.5-abliterate:7b-instruct` model) for intelligent drafting and context-aware inbox sorting.
* **Retrieval-Augmented Generation (RAG) Memory System:** Automatically saves successful actions and manual corrections to local JSON files. It feeds the 5 most recent corrective lessons back into the LLM's system prompt to prevent repeating mistakes.
* **Human-in-the-Loop GUI:** Built-in Tkinter dashboards allow the user to review, edit, or discard AI-generated email drafts and spam sweeps before execution.
* **Autonomous Inbox Sweeping:** A continuous background loop (`--auto` mode) that reads unread emails, classifies them as JUNK or URGENT using the LLM, and moves spam to the Trash folder.
* **Actionable HTML Emails:** Injects interactive `mailto:` URL-encoded buttons (Approve/Deny) directly into outgoing email bodies, allowing the system to track recipient responses automatically upon reply.
* **Non-Blocking Text-to-Speech (TTS):** Uses `pyttsx3` in a daemon thread to read notifications aloud without freezing the main execution state.

## 🛠️ Prerequisites & Installation

### 1. System Requirements
* Python 3.8+
* [Ollama](https://ollama.ai/) installed and running locally with the required model pulled:
  ```bash
  ollama run huihui_ai/qwen2.5-abliterate:7b-instruct
  ```

### 2. Python Dependencies
Install the required packages using pip:
```bash
pip install python-dotenv pyttsx3 ollama
```
*(Standard libraries used: `os`, `sys`, `io`, `imaplib`, `smtplib`, `email`, `time`, `json`, `tkinter`, `threading`, `re`, `urllib.parse`, `datetime`)*

### 3. Environment Variables
Create a `.env` file in the root directory of the script and populate it with your Yahoo Mail App Password credentials:
```env
YAHOO_EMAIL=your_email@yahoo.com
YAHOO_APP_PASSWORD=your_16_char_app_password
AI_API_KEY=your_api_key_if_applicable
```

## 🧠 System Architecture & Modules

### 1. Memory Management (`initialize_memory`, `save_memory`, `get_memory_context`)
The agent maintains its state and learns from feedback using two local JSON banks stored on the Desktop:
* `sending_email_memory.json`: Tracks drafts, successful sends, and user corrections.
* `sweep_agent_memory_bank.json`: Tracks which emails were deleted and why the LLM misclassified items (if corrected by the user).
When a new task is initiated, `get_memory_context()` parses these files and injects the history directly into the LLM's prompt.

### 2. Tkinter GUI Overlays (`review_draft_gui`, `review_sweep_gui`)
Instead of acting as a black box, the agent surfaces its intentions to a UI:
* **Drafting:** Shows the generated `TO`, `SUBJECT`, and `BODY`. The user can edit the text, approve it, discard it, or click **Corrective Learning** to log feedback on why the draft was poor.
* **Sweeping:** Displays a scrollable checklist of recent emails. Items the AI flagged as spam are pre-checked. The user can adjust the checkboxes before executing the deletion. Note: The system intelligently logs out of the IMAP server while the GUI is open to prevent Yahoo timeout disconnects, reconnecting only upon approval.

### 3. Parsing & SMTP/IMAP Logic
* **Drafting (`draft_and_send_email`, `send_via_smtp`):** Extracts headers using regex (`TO:`, `SUBJECT:`, `BODY:`). Formats the body into HTML and injects custom `mailto:` links to track recipient approvals/denials.
* **Sweeping (`sweep_inbox`, `auto_sweep_loop`):** Uses IMAP `UID SEARCH` to find unread mail. Decodes complex email headers securely, truncates bodies to 300 characters for token efficiency, and asks the LLM for a JSON array of `junk` indices to trash.
* **Approval Tracking:** Scans incoming email subjects for the strings `APPROVE:` or `DENY:` (generated by the HTML buttons in outgoing mail) and automatically logs the recipient's decision into the RAG memory bank.

## 💻 CLI Usage

The script is driven entirely via command-line arguments. 

### Draft an Email
Pass a natural language prompt as an argument. The GUI will open for review.
```bash
python script.py "Email John Smith and ask for the Q3 report update"
```

### Auto-Draft an Email (No GUI)
Add `--auto` to bypass the Tkinter review window and send immediately.
```bash
python script.py "Email John Smith and ask for the Q3 report update" --auto
```

### Sweep Inbox (Manual Review)
Fetch the latest unread emails, scan them with the AI, and open the Tkinter GUI to review the proposed spam deletions.
```bash
python script.py sweep
```

### Autonomous Inbox Sweeping
Run the sweep continuously in a loop without human intervention.
```bash
python script.py sweep --auto
```
